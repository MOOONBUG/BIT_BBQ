# 统一询价查看入口

2026-09-24：本地只读工具，已连接正式 D1 验证。

## 日常使用

在文件资源管理器打开 scripts 目录，双击 open-inbox.cmd。或在项目根目录执行 `npm run inbox`。

显示四块信息：有效询价数量、最早待处理事项、通知异常/超时记录、免费微诊断容量。时间为北京时间。付费与免费申请都在同一列表，历史内部测试和到期记录排除。列表不展示客户邮箱、网址、需求正文。

需要处理一条时执行 `npm run inbox -- detail MSC-完整编号`，查看该条客户资料。该输出只用于内部处理，勿公开粘贴。命令不发送邮件、不改变业务或通知状态。

免费项目入选、候补及交付仍使用 `npm run reviews -- ...`，详见 micro-review-operations.md。付费跟进仍按运营记录卡维护。

## 如何理解

- 查询失败会返回错误，不能当成“没有申请”。
- 待处理列表最多 100 条，汇总数量为完整有效记录统计；数量超过列表时应分批处理。
- sent 只代表服务商接受。不是客户已收到，也不是已回复客户。
- 15 分钟以上的 pending、failed 或超期 sending 列入关注。启用前记录可能仍为 pending，不能直接批量重发。
- 工具启动时读取云端，关闭后不继续监控，不是自动告警。
- .cloud-setup/inbox-last-check.json 仅保存核查时间、数量和容量；不含客户内容，已被 Git 忽略。
