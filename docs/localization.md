# Website languages

The site is statically rendered in English, Korean, Japanese, Traditional Chinese,
Russian and French. English retains the existing root URLs. Other languages use
`/ko/`, `/ja/`, `/zh-hant/`, `/ru/` and `/fr/` with the same page slugs.

## Content and maintenance

- `src/i18n/en.json` is the source copy; the other five JSON files have the same
  keys. `m001`–`m188` cover page and interaction copy; the named keys cover global
  metadata, accessibility and the downloadable enquiry brief.
- Add or edit a message in all six dictionaries together. The TypeScript shape
  check rejects missing keys, and rendering rejects blank or missing messages.
- Shared Astro pages call `useLocale(Astro.url)` to translate content and build
  internal links. The locale route reuses these pages; do not maintain six sets
  of page markup. Brand names, the fictional cup's printed wordmark and prices
  remain unchanged. The service still promises an **English report**, not
  delivery in six languages.
- Home-page interaction copy is serialized only in the current page language.
  The browser does not receive all dictionaries or call a translation service.
- The English brief remains `public/review-brief.txt`. Localized briefs are
  generated by `src/pages/[locale]/review-brief.txt.ts`; update the English file
  and translated brief keys together if its questions change.
- `pageSlugs` controls complete translated pages. Add new public pages there and
  to the route component mapping only once translations are complete. The global
  host-level 404 stays in English and offers the language selector to each home.
- Page titles, descriptions, HTML `lang`, self-canonical links and reciprocal
  `hreflang` links are localized. `x-default` points to the corresponding English
  page. The sitemap includes all 36 regular pages.

## Language picker

The compact header disclosure uses native `<details>` and real links, with each
language named in its own language. It remains available without JavaScript.
Enhancement handles Escape, outside click, focus leaving the menu, and retaining
the page anchor. Switching languages preserves the current page. Internal links
stay in that language. There is no automatic redirect, language cookie, browser
storage, third-party translation widget or added dependency.

## Validation

Run `npm run build` and `npx tsc --noEmit`. Check all six languages on desktop and
mobile, including the before/after demo, all findings and report panels, menu
keyboard interaction, no-JavaScript navigation, reduced motion, email subject,
brief download, canonical and language alternatives. Use a static preview to
check the generated output; endpoints must be tested as real `.txt` files.
